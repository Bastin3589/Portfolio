    Building the software, and understanding everything around it.

    I'm a Software Engineer who likes working where application development, backend systems and real-world problem solving meet.

    Most of my day is spent in C#, .NET, ASP.NET and SQL Server: writing features, shaping stored procedures, building REST APIs and, more recently, working with ASP.NET Core and Angular on a modernization effort. Alongside that, my work in healthcare software has taught me that code is only part of a system. When a lab result doesn't arrive, the cause might be in the application, the database, the analyzer or the network in between.

    So I've learned to follow problems across all of those layers: HL7 and ASTM messages, TCP/IP and serial connections, worklists and data flows. I bring the same habits to everything else I build, from web apps and automation to small developer tools, often using AI-assisted development to move faster without cutting corners.
